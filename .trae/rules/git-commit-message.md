## 结构
<类型>(<作用域>): <主题>

<正文>

<脚注>

### 1. 类型 (必须)
- **新增**: 新功能
- **修复**: Bug修复
- **文档**: 仅文档变更
- **格式**: 代码格式（不影响功能，如空格、分号）
- **重构**: 重构（非功能、非修复）
- **性能**: 性能优化
- **测试**: 测试相关
- **工具**: 构建过程或辅助工具变更

### 2. 作用域 (可选)
- 使用短语指明变更模块（如：api、ui、utils、db）

### 3. 主题 (必须)
- 中文描述，祈使句，无句号结尾，保持简洁明短
- 不超过50个字符

### 4. 正文 (可选)
- 每行采用-开头
- 解释“是什么”和“为什么”，而非“怎么改”，保持简洁明短
- 每行不超过72字符
